# Tileset

Handmade art goes here. The game runs with **no files at all**: every category falls back to a code-drawn
placeholder (colours in `src/render/palette.ts`, drawing in `src/render/tiles.ts`). To replace a placeholder,
drop a PNG in the right folder and add one line to `manifest.json`. No code changes.

## Folders

```
public/assets/tileset/
  manifest.json
  ground/    grass_00.png  grass_01.png  sand_00.png ...
  water/     deep.png  shallow.png  reef.png
  shore/     sand_edge.png  sand_corner.png ...        (planned: alpha masks, white = sand)
  objects/   tree_conifer_00.png  tree_leafy_00.png  hut_small_00.png  coral_00.png ...
```

## Manifest

A map from category name to a list of entries. A missing category (or a missing file) falls back to the
placeholder and logs one console warning for that category.

```json
{
  "objects.tree.conifer": [
    { "file": "objects/tree_conifer_00.png", "anchor": [0.5, 0.94], "widthInTiles": 0.8, "weight": 2 },
    { "file": "objects/tree_conifer_01.png", "anchor": [0.5, 0.94], "widthInTiles": 0.7 }
  ]
}
```

| Field | Meaning |
|---|---|
| `file` | Path relative to this folder. |
| `anchor` | Point of the image (0..1 of width, height) that sits on the ground. Default `[0.5, 0.94]`. |
| `widthInTiles` | Drawn width in tiles. Default `0.8`. |
| `weight` | Relative chance when several entries are in a category. Default `1`. |

The pick is seeded by the tile position, so it is deterministic.

## Categories

| Category | Draw as | Notes |
|---|---|---|
| `ground.grass`, `ground.sand` | 128 x 128 px, **flat top-down square**, edges wrap | 3-4 variants. The renderer rotates them and maps the square onto the iso diamond. |
| `water.deep`, `water.shallow`, `water.reef` | 256 x 256 px, tileable | `"cells"` = grid cells one copy covers (placeholders: 4; per-cell pixel art: 1, so its foam meets the shore tiles). Mipmapped. Deep = open sea, shallow = inside a folder cluster, reef = coral patch. |
| `shore.edge.n` / `.e` / `.s` / `.w` | 32 x 32 px flat square, whole tile | A coast cell with water on that side (water, foam and sand in one tile). Several entries = variants. |
| `shore.outer.nw` / `.ne` / `.se` / `.sw` | same | Coast cell with water on two sides (named by the water sides). |
| `shore.inner.nw` / `.ne` / `.se` / `.sw` | same | Land cell with water only in that corner (a bay). |
| `shore.sand`, `shore.water` | same | Coast cell with no water side, and a one-cell sand spit (drawn as water). |
| `objects.tree.conifer`, `.leafy`, `.bush`, `.dead` | up to 256 px tall, transparent PNG | Upright, anchored at the base. |
| `objects.rock`, `objects.tuft` | small transparent PNG | Scenery on grass. |
| `objects.hut.small`, `.medium`, `.large` | transparent PNG | One house (a function). Villages are clusters of these, arranged by code. |
| `objects.village` | transparent PNG | Optional: a whole pre-drawn village. If present it replaces the code-arranged cluster. |
| `objects.coral` | transparent PNG | A coral head that sits in reef water, no sand edge. |
| `objects.port` | transparent PNG | A dock. |
| `objects.shadow` | transparent PNG | Optional soft shadow under objects. |

## Style

Painted or flat-vector art. Pixel art shimmers and blurs under continuous zoom. Author at about 2x the
largest on-screen size; mipmaps handle zooming out. Ground and water must tile seamlessly; give transparent
objects a few pixels of padding.

## Shore tiles

The current shore, water and sand art is generated by `art/piskel/make_shore_tiles.py` (source: `art/piskel/shore_tiles.piskel`).
Re-run it with this folder as the last argument to re-export the PNGs and update the manifest entries.
